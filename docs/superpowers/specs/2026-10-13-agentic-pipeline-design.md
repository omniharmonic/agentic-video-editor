# Agentic Video Pipeline: design

> **Internal design history.** A working plan or spec written for the agents that built this part of the toolkit. It is kept as a record of intent and is not user documentation; the code, `AGENTS.md`, the skills and the reference docs are authoritative. Paths and names in it describe the first project. See [docs/README.md](../../README.md).

Date: 2026-10-13. Status: approved by the author ("use your best judgement ... build out the entire system end to end").
Supersedes the Resolve-centred plan in the earlier README. Research digests that informed this design are summarized under "Evidence".

## Goal

An agent-agnostic toolkit that takes raw multicam podcast footage to published, reviewed content, with a human at
checkpoints. Claude (or any agent) does the judgment; deterministic CLI tools do the mechanical work; every step leaves a
JSON artifact on disk so any new session resumes instantly. DaVinci Resolve (free 21.0.x) is the **human review and polish
surface**, not the editing engine.

## Decisions

1. **FFmpeg + Python are the engine.** Resolve free cannot split/trim/move items, has no fades/transitions/speed API, no subtitle
   styling API, and one Studio-gated call (`CreateSubtitlesFromAudio`) blocks all later API calls behind a modal. So edits are
   *compiled*, never edited in place.
2. **One contract: `edit.json` (EditDoc v1).** Every stage reads/writes it. Compilers render it to media; the Resolve handoff
   builds a timeline from it. Tracks are in **output time** with a per-segment source mapping, so J/L cuts and removed
   sections are natural.
3. **Three cut stages** (the editor's mental model): **assembly** = all angles synced, shot/reverse-shot switched, nothing
   removed; **rough** = cleanup applied (dead air, fillers, false starts) with edits masked; **final** = rough + captions,
   overlays, music, motion graphics, loudness, approved by the human. Each is a versioned file `edits/<stage>.vN.json`.
4. **Audio is compiled separately** from video into one clean dialogue master (sample-accurate cuts, crossfades, room tone).
5. **Captions are generated by us** (SRT from transcript, ASS for styled/karaoke), burned in by FFmpeg; the SRT sidecar is kept. The final render is
   re-transcribed to regenerate exact SRTs.
6. **Episode state is our own manifest** (`episode.json` + `edits/` + `work/`), with `ave status` / `ave resume` printing a
   briefing a fresh session can act on. No dependence on Resolve for state.
7. **Taste lives in policy files** (YAML) and skills, never buried in code. Every automated judgment writes its reason and
   confidence so the human can audit it.
8. **Publishing is gated**: a local approval queue; nothing leaves the machine without `ave publish approve`. Direct
   YouTube + Facebook; adapter for an aggregator (Instagram/X); credentials only from the OS keychain/env.
9. **Optional heavy deps** (face detection, embeddings, Playwright) are extras with graceful fallbacks and clear doctor output.

|---|---|---|
| `editdoc` (core) | EditDoc schema, validation, episode<->output time maps | `edits/*.json` |
| `state` (core) | stage graph, status, resume briefing, edit versioning | `episode.json` |
| `assemble` | cutlist -> assembly EditDoc | `edits/assembly.v1.json` |
| `cleanup` | detect dead air/fillers/repeats/false starts, decide with policy, mask with cameras/punch-ins, emit rough EditDoc | `work/cleanup.json`, `edits/rough.vN.json` |
| `compile` | EditDoc -> audio master, video, proxy/preview, loudnorm | `exports/*.mp4`, `work/render/*` |

## EditDoc v1 (the contract)

```
{ "version": 1, "stage": "assembly|rough|final|select|short", "fps": 30.0,
  "canvas": {"w":1920,"h":1080},
  "sources": {"A": {"file":"raw/camA.mov","kind":"video","start_offset":0.0,"drift_ppm":50.0}, "M": {"file":"raw/rec.wav","kind":"audio","start_offset":1.2,"channel_map":[{"start":0,"end":7035,"use":"right"}]}},
  "tracks": {
    "video":    [{"id","src","o0","o1","e0","crop":[x,y,w,h]|null,"zoom":1.0,"reason","confidence"}],
    "dialogue": [{"id","src","o0","o1","e0","xfade_ms":0,"gain_db":0,"reason"}],
    "room_tone": {"src","e0","e1"} | null,
    "music":    [{"id","file","o0","o1","in":0.0,"gain_db":-20,"duck_db":-8,"fade_in_s":0,"fade_out_s":0,"license":{}}],
    "overlays": [{"id","file","o0","o1","x","y","w","h","layer","kind":"motion|broll|caption","alpha":true}] },
  "captions": {"srt":null,"ass":null,"burn":false},
  "duration": 0.0, "notes": "" }
```
`e0` is **episode time** (the reference timeline, conventions as in AGENTS.md). Source clock = `(e - start_offset) / (1 + drift_ppm*1e-6)` (`editdoc.source_time`; `drift_ppm` defaults to 0; an optional `channel_map` lists source-clock ranges where one channel is dead, `use` = `left|right|mix|sum`; the compiler folds the live channel to dual mono, or for `sum` (a speaker-per-channel master) plays L+R, soft-limited, on both ears). Per-session edits are NAMED (`assembly.s1.v1.json`) and carry `session` and `excluded` (episode-time ranges no camera covers). Video and
dialogue lists are independent so a video boundary may differ from an audio boundary (J/L cut). Valid docs have gap-free,
non-overlapping `video` and `dialogue` covering `[0,duration]`.

## Evidence (what shaped it)

- Resolve limits: local `api-limitations.md` and README of the MCP; free build measured on 21.0.4.
- Cleanup: fillers are kept/cut by duration and clustering; room tone not silence; crossfades 5-15 ms in speech, 20-40 ms across gaps;
  cut masking prefers the other camera, then a wide, then a 110-120% punch-in (numbers are tunable defaults, to be calibrated by listening).
  Parakeet **does** emit fillers on the author's audio (20 "um" vs Whisper-plain 5), so one ASR engine suffices.
- Clips: LLM selects by **sentence ID** against a weighted rubric; boundaries snap to sentence edges; human review via contact sheet.
- Shorts: MVP is one static face-centred 9:16 crop per speaker camera, cutting on speaker change; ASS captions burned in; -14 LUFS two-pass.
- Publishing: YouTube/Facebook direct APIs are free and local-friendly; Instagram needs a public URL and app review, X is pay-per-use.
- Motion: renderer must be license-clean for an open-source repo; HTML/GSAP via Playwright to ProRes 4444 alpha, Remotion as optional adapter.

## Non-goals (v1)

Native multicam clips, in-Resolve editing, Studio-only features, auto-posting without approval, Windows/Linux transcription.

## Testing

Pure logic has unit tests. Media stages have a synthetic fixture generator (`tests/fixtures.py`: tone/noise "speech", two cameras
as colored test patterns with known offsets) so CI runs without private footage. A real-footage smoke script exercises the whole
chain locally. Every compiler is verified by ffprobe of the output (duration, streams, fps) and, for audio, by measured loudness.
