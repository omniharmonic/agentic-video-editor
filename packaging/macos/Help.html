AVE Studio

AVE Studio is a local video workspace. You direct and review here, your AI agent does the labor, and DaVinci Resolve and Canva handle the craft. Your footage stays on your Mac.

First run

  1. Drag AVE Studio to Applications and open it. Choose or create a workspace.
  2. To let your agent work, open Terminal once and run:
    "/Applications/AVE Studio.app/Contents/MacOS/AVE Studio" --install-cli
    This adds the ave command, adds the agent skills to Claude Code, and installs the DaVinci Resolve bridge. It never replaces files it did not create.
  3. If Terminal says ave is not found, add ~/.local/bin to your PATH.
  4. Run ave doctor to see what is ready.

DaVinci Resolve

Use Resolve 21.0.x. Free Resolve needs Python 3 installed from python.org for its Scripts menu. Open a project made for this work, then choose Workspace > Scripts > resolve_bridge. Your agent builds new timelines and never changes existing ones. Captions need one manual step on free Resolve: File > Import > Subtitle.

Working with a collaborator

  1. Both people install Tailscale from tailscale.com (not the App Store) and join the same tailnet.
  2. In Collaborate, choose Enable sharing and pick an exchange folder outside your studios and footage.
  3. One person creates an invitation and sends it directly. The other adds it. Compare the six-digit code by voice, then both confirm.
  4. Share drafts from Collaborate. Use Send a file for footage or edits. Transfers resume if the connection drops, and each file is verified as a whole.

Received files stay in the exchange folder until you import them. Approvals, accounts and publishing never cross. Stop sharing or Revoke collaborator ends access immediately.

What stays human

Approving, publishing and setting trims are yours. Your agent cannot sign off for you, and nothing is posted without your approval.
